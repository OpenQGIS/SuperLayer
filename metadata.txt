    Version 2.4.0:
    - ✨ 新增临时矢量图层统一批量保存窗口，支持将多个图层保存到同一 GeoPackage、KML、FileGDB 或 Shapefile 文件夹。/ Added a unified batch export dialog for saving temporary vector layers to one GeoPackage, KML, FileGDB, or Shapefile folder.
    - 🚀 优化批量保存流程，支持格式联动路径、名称冲突处理、逐层写入验证及统一结果汇总。/ Improved batch saving with format-aware destinations, name conflict handling, per-layer validation, and a consolidated result summary.
    - 🚀 临时图层导出后完整保留原有符号渲染、标注、图表及其他项目样式。/ Preserved symbology, labeling, diagrams, and other project styles when exporting temporary layers.
    - 🐛 修复批量保存替换临时图层时，保存结果与思维导图访问已释放图层对象导致的运行错误。/ Fixed runtime errors caused by save results and the mind map accessing released layer objects after batch replacement.

    Version 2.3.0:
    - ✨ 文件夹视图、思维导图与矩形树图全视图支持主干文件夹、文件类型及各层级节点的不可见图标遮罩与视觉反馈。/ Added invisible icon overlays and visual feedback across folder trees, mind maps, and treemap views for folder, file-type, and layer nodes.

    Version 2.2.0:
    - 🐛 修复"只展示显示图层"过滤逻辑：群组不可见时，群组内已勾选的子图层也会被正确过滤排除，不再显示在列表中。/ Fixed "Show visible layers only" filter logic: layers inside invisible groups are now correctly excluded from all views, even when their own checkbox is checked.
    - ✨ 不可见的群组与文件夹图标叠加半透明隐藏遮罩，与图层的视觉反馈保持一致。/ Invisible group and folder items now display a dimmed hidden-icon overlay, visually consistent with the treatment of hidden layers.

    Version 2.1.0:
    - ✨拖拽图层或文件夹物理重定位时，弹窗提供“移动”、“复制”、“备份”三个选项，并匹配专属 SVG 图标。/ Added Move, Copy, Backup selection dialog with matching SVG icons when dragging layers or folders.
    - ✨选择操作弹窗中直观列出所操作图层的所有关联物理伴生文件（如 .shp, .prj, .dbf, .pdf 等），保障操作透明。/ Listed all companion physical files (such as .shp, .prj, .dbf, .pdf) in the selection dialog.
    - ❗ 优化取消按钮背景色为深灰色，提升弹窗视觉层级；修复 PyQt5/PyQt6 addButton 图标签名类型不匹配问题。/ Darkened the cancel button background for better hierarchy and fixed QMessageBox.addButton icon signature compatibility.

    Version 2.0.0:
    - ✨新增“只展示显示的图层”过滤功能，点击过滤按钮可即时刷新视图过滤隐藏图层。 / Added "Show visible layers only" filter to immediately refresh the view and filter hidden layers.
    - ❗ 优化隐藏图层的图标展示，维持图层树与批量修改看板的视觉一致性。 / Optimized hidden layer icons to maintain visual consistency between the tree and the batch modification board.
    - 🐛修复矩形树状图面板中超长文件名换行时文字显示不全的剪裁问题。 / Fixed text clipping issue for wrapping extremely long filenames in the Treemap.
    - 🐛 修复在图层目录树中拖放文件夹物理迁移时偶发的 AttributeError 异常。 / Fixed occasional AttributeError when dragging and dropping folders for physical migration in the tree.

    Version 1.9.0:
    - ✨ 新增文件夹右键“迁移文件夹”功能与思维导图内拖拽移动文件夹位置。 / Added right-click "Migrate Folder" action and support for drag-and-drop folder relocation in the mindmap view.
    - ✨ 新增思维导图框选图层（框选模式）功能，并支持通过拖动快速迁移图层。 / Added marquee selection in the mindmap view and support for dragging on the layer name column to quickly migrate layers.
    - ✨ 新增批量修改面板的只展示显示图层过滤选项。 / Added a filter option in the batch modification board to show visible layers only.
    - 🚀 优化图层取消显示时的图标展示，使其仍保留具体的图层类型图标。 / Improved hidden layer rendering to retain specific layer type icons instead of hiding them behind a hide icon.
    - 🚀 重构右键菜单显示与隐藏图层动作，支持根据当前图层可见性状态动态排序并使用更美观的组件图标。 / Reordered show/hide layer actions dynamically based on layer visibility and upgraded their icons to modern component SVGs.

    * 🌐 多语言支持与本地化适配：新增阿拉伯语、德语、英语、西班牙语、法语、意大利语、日语、韩语、葡萄牙语、俄语及中文等12种语言的完整国际化支持，智能识别 QGIS 区域设置并自适应切换界面语言。/ Added full localization and multi-language support for 12 languages including English, Chinese, Arabic, German, Spanish, French, Italian, Japanese, Korean, Portuguese, and Russian, automatically adapting to QGIS locale settings.
